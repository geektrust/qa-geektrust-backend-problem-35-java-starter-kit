# Peak Traffic Window

Write your solution in `src/main/java/Main.java`, inside the `peakWindow` method. Input is read from standard input and the result is printed to standard output, as described in the problem statement.

---

## 🚀 How to Run

```bash
./run.sh
```

This compiles and runs `Main.java` with the contents of `sample_input.txt` as input. Edit that file to try other inputs.

---

## 🧪 Run Tests

Unit tests are located in `src/test/java/TestSample.java`. Add your own cases there to check your work.

```bash
./run_unittests.sh
```

---

## 🗂️ Project Structure

```text
├── src/main/java/Main.java        # Write your solution here
├── src/test/java/TestSample.java  # Unit tests
├── sample_input.txt               # Input used by run.sh
├── run.sh                         # Runs your solution
├── run_unittests.sh               # Runs all unit tests
├── build.xml                      # Ant build file (clean, compile, dist, run, test)
└── README.md                      # This file
```
